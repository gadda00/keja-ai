## 2. Architecture and Core Design Decisions

- **One bundle, three runtimes** — the same `out/` static export serves the web (Netlify CDN), the installed PWA (manifest + service worker + offline shell), and the Capacitor Android/iOS shells. Web and store builds cannot drift.
- **Hash routing** (`src/lib/router.tsx`) — pure static artefact; deep links resolve to `index.html`; Netlify `/* → /index.html` keeps legacy path URLs graceful. SEO surfaces handled via sitemap/robots/prerendered metadata.
- **State and data spine** — typed stores (`src/lib/*Store.ts`, Zustand-style) persist to localStorage. Inventory is compile-time: `src/data/properties.ts` (seed) + `src/data/auto-listings.json` (Auto-Pilot). Everything versioned in git, reviewable, reproducible.
- **Backend graduation path** — Prisma + local SQLite already in the sandbox; `NEXT_STATIC` flag switches static vs standalone server build; stores isolated behind library boundaries.

## 4. Data and Intelligence Layer

- **Auto-Pilot pipeline** — every 6h (04:10/10:10/16:10/22:10 UTC) `scripts/auto-listings/run.mjs` scans sources and feeds, AI-enriches, dedupes, quality-gates and publishes into `auto-listings.json`; commits as `keja-autopilot[bot]`, which triggers the production deploy. Zero-human marketplace growth.
- **Trust Score & Passport** — 12 labelled, individually inspectable factors; Property Passport carries KEJA-XXX-000000 identity, ownership/title/encumbrance/rates/zoning status, valuation band, fraud risk, 90-day evidence freshness.
- **AI advisor & Deal Analyst** — trilingual, intent-routed, professional-advice escalation guard; Deal Analyst processes documents on-device (never uploaded) and returns Proceed/Negotiate/Investigate/High-Risk.
- **Keja Data** — yields and comparisons computed live with declared sample sizes.

## 5. Progressive Web App

- **Manifest**: standalone (+minimal-ui fallback), maskable icons 192/512 with safe-zone padding, shortcuts (Properties, Ask Keja, Deal Analyst), narrow+wide screenshots for Chromium rich install, `launch_handler: navigate-existing`.
- **Service worker** (`public/sw.js`): three caches (assets/images/pages); cache-first immutable assets; network-first navigations with 8s timeout → cached page → shell → `offline.html`. Cache version content-hashed by `scripts/sw-version.mjs` — stale caches self-evict on activate.
- **iOS Safari**: 17 device-class launch screens (`public/splash/`, generated by `scripts/generate-pwa-assets.mjs`), `apple-mobile-web-app-capable` (both forms), black-translucent status bar + safe-area padding, Share→Add-to-Home-Screen walkthrough in `InstallPrompt.tsx` (14-day dismissal memory, Capacitor/standalone aware).
- **Verified live**: manifest, `sw.js` version `v43c8cafcbc2d`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff` on the edge.

## 7. Quality Pipeline

| Workflow | Trigger | Does |
|---|---|---|
| PR check | PRs, non-main pushes | typecheck + lint + static build |
| Deploy to Netlify (keja.app) | main pushes | same gates → zip `out/` → Netlify API deploy |
| Auto-Pilot listings | cron 6h | ingest → commit → re-trigger deploy |

**Post-mortem (early Sept 2026)**: every deploy failed because workflows ran `npm ci` while the repo lockfile is `bun.lock` (no `package-lock.json`). Ingest kept succeeding because it is zero-dependency. Fix in `ab30a10`: `oven-sh/setup-bun@v2` + `bun install --frozen-lockfile`, credentials guard, `_redirects`/`_headers` presence check. Next run: green end-to-end.

**API-zip deploys never read `netlify.toml`** — redirect/header rules must ship inside `out/` as `public/_redirects` and `public/_headers` (mirrors of netlify.toml). This was a latent gap until Sept 2026; both are now verified live.

## 10. Development Guide

```bash
bun install --frozen-lockfile     # install exactly the locked tree
npm run dev                       # dev server :3000
npx tsc --noEmit                  # typecheck (CI gate)
npm run lint                      # eslint (CI gate)
npm run build:static              # NEXT_STATIC=1 next build -> out/
node scripts/sw-version.mjs       # stamp SW cache version
node scripts/generate-pwa-assets  # regenerate icons/splash/screenshots
npm run mobile:sync               # sync out/ into android + ios
npm run mobile:apk                # debug APK
```
